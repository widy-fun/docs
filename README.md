# Widy Docs

This repository contains the documentation website for Widy, built with [Docusaurus](https://docusaurus.io/).

## Requirements

- Node.js `>= 20.0`
- `npm` or `yarn`

## Install dependencies

Using npm:

```bash
npm install
```

Using yarn:

```bash
yarn
```

## Local development

Start the local development server:

```bash
npm run start
```

or

```bash
yarn start
```

The site will be available at `http://localhost:3000` and supports live reloading.

## Build

Generate a production-ready static site:

```bash
npm run build
```

or

```bash
yarn build
```

The output is written to the `build` directory.

## Serve locally

Preview the built site:

```bash
npm run serve
```

or

```bash
yarn serve
```

## Clear cache

Clear the Docusaurus cache and temporary files:

```bash
npm run clear
```

or

```bash
yarn clear
```

## Deploy

Deploy the site using Docusaurus deploy:

```bash
npm run deploy
```

or

```bash
yarn deploy
```

If deploying to GitHub Pages, you can configure deployment with `USE_SSH=true` or `GIT_USER=<Your GitHub username>` as needed.
