# Settings

## Wheel Settings

You can configure how much time is added for new donations, leader changes, or new lots.

![Wheel Settings](./img/wheel_settings.png)

These options let you extend the auction dynamically as activity increases:
- New donation: add time when a donation is received
- Leader change: add time when the top lot changes
- New lot: add time when a new lot is added during the auction
