# Introduction

Welcome to Widy! This guide will help you get started with the application and set up your widgets.

## Requirements

Before you begin, ensure that **port 12553** is open on your system. This port is required for the app to function properly.

## Getting Started

To display widgets in OBS, follow these steps:

1. **Start the app** - Launch the Widy application on your computer
2. **Run OBS** - Open Open Broadcaster Software (OBS) after the app is running
3. **Configure widgets** - Add and customize your widgets in OBS using the app's settings
